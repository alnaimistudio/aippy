# Deep Catch

Portrait mobile web fishing game for Aippy.

## Entry point
Open `index.html`.

## Files
- `index.html` — game shell/UI
- `style.css` — mobile portrait UI styles
- `game-render.js` — gameplay, shop, rods, fish logic and rendering
- `rod-assets.js` — embedded rod artwork
- `fish-assets.js` — embedded fish artwork

All assets are embedded in the game folder so this game is self-contained and does not depend on other games in the repository.
